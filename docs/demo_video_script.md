## SCREEN RECORDING INSTRUCTIONS

1. Use OBS Studio or Loom for recording
2. Set resolution to 1920×1080, 30fps
3. Record system audio + mic simultaneously
4. Do a practice run at 1.5x normal speed to verify timing
5. Export: MP4, H.264, ~50MB max for upload
